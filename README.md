# Лабораторная работа №3
Консольное приложение на языке C#
## Функционал программы
1. **Guess the answer** — вычисление математической функции с проверкой ОДЗ и мини-игра на угадывание результата за 3 попытки.
2. **About the author** — вывод информации об авторе работы и номере группы.
3. **Array sorting** — генерация случайного массива, сортировка пузырьком и выбором с замером времени выполнения (`Stopwatch`).
4. **Exit** — выход из программы с подтверждением (`д/н`).

## Запуск
В папке проекта выполните команду:
`dotnet run`
